Write translated prose entirely in the target language, using natural translations or transliterations for names, titles, and forms of address; retain source spelling only for literal identifiers or established target-language usage, and never copy raw source names from guides or summaries into prose.
For foreign-language wording embedded in the source (a third language neither source nor target), default to original wording followed by its target-language translation in parentheses; keep text already in the target language without duplicating it. This exception does not make ordinary source text or names bilingual, and ordinary source terms or idioms must not receive parenthetical glosses or translator notes.
