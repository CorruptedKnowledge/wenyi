Write translated content entirely in the target language, using conventional translations or transliterations for names, titles and forms of address. Retain source spelling only where context requires it (such as literal identifiers or established target-language usage). Original names in guides and summaries identify referents; do not copy them into prose.
For foreign-language wording embedded in the source (a third language neither source nor target), default to original wording followed by its target-language translation in parentheses, using target-language punctuation; keep wording already in the target language without duplicating it. This exception does not make ordinary source text or names bilingual, and ordinary source terms or idioms must not receive parenthetical glosses or translator notes.
